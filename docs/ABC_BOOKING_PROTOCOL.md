# ABC Booking Protocol

Generated by `scripts/probe-abc-booking.ts`. **Dev-only — never auto-submit in production.**

## Go / No-Go Verdict

| Verdict | **GO** |
|---------|--------|
| Reason | ABC exposes JSON POST endpoints with base64-encoded payloads. Server-side proxy is feasible for catalog, shop hours, and staff. Final submit requires additional encrypted payload research. |

## JSON API (discovered)

All requests: `POST https://abcapp.us/feedback/appointment?appid=tI8PdCO` with `Content-Type: application/json`.

| Request body | Response field | Contents |
|--------------|----------------|----------|
| `{"services_crypt":"demo"}` | `services` | Base64 JSON — category → service → `{ price, duration, index, ... }` |
| `{"shop_crypt":""}` | `shopinfo` | Base64 JSON — salon name, phone, weekly hours |
| `{"employees_crypt":""}` | `crypt` + `employees` | Staff names + availability matrix; `crypt` token for session |

Service ID format used by Milano: `categoryKey::serviceName::index` (e.g. `manicure::delux mani::5`).

### Session requirements

- No browser cookies required for catalog/shop/employees fetches
- `employees_crypt` response includes a `crypt` hash — stored server-side per booking session
- Final booking submit likely requires additional encrypted payloads (not yet mapped)

### Native UI architecture

1. Browser calls `/api/booking/*` only
2. Next.js server calls ABC JSON endpoints
3. CMS services merged via `abcServiceId` or fuzzy name match
4. Submit gated by `ABC_BOOKING_ENABLED=true` (default off in `.env.example`)
5. Hard cap `ABC_BOOKING_MAX_PER_DAY` (default **1**) — persisted in `.data/abc-submit-quota.json`

### Submit payload

```
POST { command: "newappointment", appid: "demo", appointment: "<base64 JSON>" }
```

Decoded appointment includes services (`name` = category, `children` = ABC service key), `date` (M/D/YYYY), `hour` (`09:30 AM`), phone digits, staff `request`, and shop option fields.

## Fallback

If native proxy fails mid-flow, visitors see an error and **Open ABC Salon booking** link. Iframe facade remains available when native toggle is off.
